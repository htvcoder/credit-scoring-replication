# Data Card: TH02

## Nguồn và phiên bản

- Dataset: public credit scoring data from *Credit Scoring and Its Applications*, Thomas, Edelman and Crook, SIAM, 2002.
- Registry entry: `data/datasets.yaml`, dataset id `th02`.
- Raw data: `data/raw/th02/public.xls`.
- Dictionary: `data/raw/th02/publicdict.xls`.
- Processed conversion artifact: `data/processed/th02/th02.csv`.
- Raw format: Microsoft Excel BIFF2 legacy workbook; this is a tool compatibility issue, not evidence of a corrupted dataset.

## Conversion Method

The reusable command is:

```powershell
python scripts/convert_th02.py --input data/raw/th02/public.xls --output data/processed/th02/th02.csv
```

The successful conversion used `xlrd` and did not modify `data/raw/th02/public.xls`. The script validates shape, schema, target domain, class counts and absence of generated index columns before writing output.

## Dictionary Notes

`publicdict.xls` is readable with `xlrd`. It contains a variable dictionary in `Sheet1`; `Sheet2` and `Sheet3` are empty.

## Preprocessing Status

The CSV conversion preserves values and schema for tooling compatibility. No imputation, WOE, VIF, class balancing, split creation, or duplicate removal has been applied. Duplicate rows are retained to preserve the 1,225 observations used by the paper.

Numeric columns are `DOB`, `NKID`, `DEP`, `PHON`, `SINC`, `DAINC`, `DHVAL`, `DMORT`, `DOUTM`, `DOUTL`, `DOUTHP`, `DOUTCC`. Categorical columns are `AES`, `RES`. There are no identifier or ignored columns.
